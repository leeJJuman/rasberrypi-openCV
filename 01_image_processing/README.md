# Image Processing

## Purpose

OpenCV를 이용하여 이미지의 기본적인 처리 방법을 실습했습니다.

## Environment

- Raspberry Pi 4
- Python
- OpenCV

## Practice

- 이미지 불러오기
- Grayscale 변환
- 이미지 Flip
- 이미지 Rotate
- Canny Edge Detection
- Gaussian Blur
- Circle 그리기
- Rectangle 그리기

## Description

하나의 이미지를 불러온 후 다양한 OpenCV 기능을 적용하여
각 처리 결과를 비교했습니다.

Grayscale 변환을 통해 이미지를 흑백으로 변환하고,
Flip과 Rotate를 이용하여 이미지의 방향을 변경했습니다.

또한 Canny Edge Detection을 이용하여 이미지의 윤곽선을 검출하고,
Gaussian Blur를 이용하여 이미지에 Blur 효과를 적용했습니다.

마지막으로 Circle과 Rectangle을 이미지 위에 그려
기본적인 도형 그리기 기능을 실습했습니다.
