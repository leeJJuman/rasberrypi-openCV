# Capture Image

## Purpose

실시간 카메라 영상에서 원하는 순간의 프레임을
이미지 파일로 저장하는 방법을 실습했습니다.

## Environment

- Raspberry Pi 4
- Raspberry Pi Camera
- Python
- OpenCV
- Picamera2

## Practice

- 실시간 카메라 영상
- 키보드 입력
- 현재 프레임 캡처
- PNG 이미지 저장
- 저장 디렉터리 생성

## Description

Picamera2를 이용하여 실시간 카메라 영상을 출력하고
키보드 입력을 이용하여 원하는 순간의 프레임을 저장하도록 구현했습니다.

S 키를 누르면 현재 카메라 프레임을 PNG 파일로 저장하며,
저장할 이미지의 번호를 증가시켜 여러 장의 이미지를 저장할 수 있도록 했습니다.

저장 디렉터리가 존재하지 않는 경우
프로그램 실행 시 자동으로 디렉터리를 생성하도록 구현했습니다.

Q 키를 누르면 프로그램을 종료합니다.

## Result

실시간 카메라 영상에서 원하는 순간의 이미지를
PNG 파일로 저장하는 것을 확인했습니다.
