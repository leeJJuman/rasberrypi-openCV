# Camera

## Purpose

Raspberry Pi Camera와 Picamera2를 이용하여
실시간 카메라 영상을 출력하는 방법을 실습했습니다.

## Environment

- Raspberry Pi 4
- Raspberry Pi Camera
- Python
- OpenCV
- Picamera2

## Practice

- Raspberry Pi Camera 초기화
- Picamera2 설정
- 실시간 영상 캡처
- OpenCV를 이용한 영상 출력
- 영상 중앙 좌표 계산
- 영상 중앙에 Circle 표시

## Description

Picamera2를 이용하여 Raspberry Pi Camera를 초기화하고
640x480 크기의 실시간 영상을 입력받았습니다.

입력된 영상의 중앙 좌표를 계산하고
영상 중앙에 원을 표시하여 카메라 영상의 위치 정보를 확인했습니다.

## Result

Raspberry Pi Camera에서 입력되는 실시간 영상을
OpenCV 화면에 출력했습니다.
