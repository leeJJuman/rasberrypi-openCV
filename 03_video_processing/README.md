# Video Processing

## Purpose

실시간 카메라 영상에 OpenCV의 영상 처리 기능을 적용하는
방법을 실습했습니다.

## Environment

- Raspberry Pi 4
- Raspberry Pi Camera
- Python
- OpenCV
- Picamera2

## Practice

- 실시간 영상 입력
- Canny Edge Detection
- Flip
- 실시간 영상 처리

## Description

Picamera2를 이용하여 실시간 카메라 영상을 입력받은 후
Canny Edge Detection을 적용하여 영상의 윤곽선을 검출했습니다.

검출된 Edge 영상에 Flip을 적용하여
변환된 결과를 실시간으로 출력했습니다.

## Result

실시간 카메라 영상에 Canny Edge Detection과
Flip을 적용한 결과를 확인했습니다.
